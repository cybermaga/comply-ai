# Normfold identity

## Name and language

- **Normfold** is the product name in prose, document titles and metadata.
- **normfold** is the lowercase wordmark, set in DM Sans 600 with `-0.04em` letter spacing.
- Descriptor: **AI compliance. Grounded in evidence.**
- Main headline: **Clarity, before deployment.**
- Product sequence: understand the system → establish the evidence → make the next step clear.

Use evidence-led language: available, partial, missing, needs review, preliminary assessment and human review. A missing document is an evidence gap; it is not automatically proof of a legal violation. Do not describe the public demo as a live assessment or claim certification, guaranteed compliance, unverified processing speed or unsupported adoption figures.

## Visual system

| Token | Value | Use |
|---|---|---|
| Paper | `#FAF9F5` | Primary canvas. |
| Ink | `#242927` | Body text, important rules, dark surfaces. |
| Cobalt | `#244AC5` | Principal action, active state, signature mark. |
| Muted | `#666B65` | Secondary text. |
| Rule | `#DCDFD6` | Fine dividers. |
| White | `#FFFEFA` | Workspace surfaces. |
| Wash | `#F0F1EB` | Secondary surfaces. |
| Blue wash | `#EDF0FB` | Evidence detail and selected context. |

Display typography: **Instrument Serif**, with Georgia and Times New Roman fallbacks. Interface and body: **DM Sans**, with platform sans serif fallbacks. Labels and technical metadata: **IBM Plex Mono**, with system monospace fallbacks.

Use fine rules, readable tables, generous space and restrained editorial typography. The folded-line mark is an open geometric motif. Avoid certification stamps, shields, robot imagery and decorative compliance scores. Colour always accompanies a text label for status.
