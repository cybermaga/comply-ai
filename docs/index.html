01 / The workflow

From a system description
to a reviewable evidence file.

Normfold brings the context, supporting material and outstanding questions together. The guided demo follows a readiness assessment from intake through to a report preview.

  1. 01 — UNDERSTAND

    Start with the context.

    Describe the system’s purpose, users, affected people and role in decisions. Make the assumptions visible before assessing the requirements.

    System profile / Structured intake
  2. 02 — EXAMINE

    Connect the evidence.

    Review the available documentation, explore a preliminary classification and make the gaps between requirements and evidence explicit.

    Evidence review / Assessment / Gap matrix
  3. 03 — RESOLVE

    Give each gap a next step.

    Bring findings into a remediation roadmap with owners, then organise the assessment for a qualified human reviewer.

    Remediation / Report / Human review
